# Exploratory historical comparison

This folder holds a non-destructive reproduction harness for Othmane's
nine-asset joint stylized-fact study and the M2 Stage-3 anchor. See
[PLAN.md](PLAN.md) for the full comparison sequence and
[RESULTS.md](RESULTS.md) for the latest numbers and offline Plotly figures.
The consolidated [issues and limitations note](OTHMANE_APPROACH_ISSUES.md)
separates confirmed source defects from statistical caveats.

Run from the repository root with Python 3.10+ and NumPy, SciPy and pandas:

```bash
python matteo/model_comparison/othmane_replication/audit_targets.py \
  --output matteo/model_comparison/othmane_replication/target_audit_001.json
python matteo/model_comparison/othmane_replication/compare.py \
  --asset SP500 --models both --days 1000 --burn-days 252 \
  --paths 8 --seed 93271 --output /tmp/othmane_m2_sp500.json
```

The target audit also needs openpyxl to read the historical index workbook.

The command evaluates saved parameters. It does **not** optimize M2 or
reproduce the historical study's published 40-replicate confidence bands.
The score uses Othmane's exact historical residual code for both models.
The observed OHLC variance proxy differs from both models' current variance
outputs, so roughness, leverage and Zumbach fit are exploratory until the
common measurement layer in `PLAN.md` is complete.

The source audit finds two blocking defects in the legacy joint-calibration
entry point: five initial coordinates for a six-coordinate optimizer, and a
53-entry invalid-region penalty for a 59-entry normal residual. Its Stage-2
`m1` bisection also defaults to `alpha=1` instead of the fitted alpha. The
archived final parameters can be evaluated but cannot be regenerated by
executing that entry point as checked in.

The newer exploratory run evaluates all nine assets on 20 fresh paths of
4,000 retained days and saves per-path statistics in
[`nine_assets_fresh_001.json`](nine_assets_fresh_001.json). A separate screen
selects among 32 existing M2 readouts on pre-2015 return facts and evaluates
later historical targets in [`m2_readout_screen_001.json`](m2_readout_screen_001.json).
Open [the Plotly overview](plots/overview.html) or the
[early-selection plot](plots/readout_screen.html) to inspect the results.
