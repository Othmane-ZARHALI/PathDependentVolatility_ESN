# Experimental current-reference components

The original M2 package remains in `matteo/exogenous_reservoir_eq_m2`. The `m2_spx` and `m2_vix` diagnostic module names remain available through the option-pricing package. They use the original M2 anchor and are not the two-speed model.

`two_speed.py` contains the two-speed conditional VIX response and price/Jacobian calculation, extracted from the archived calibration implementation. It expects the caller to supply conditional nodes, draws, quotes, controls and model parameters. `rotation.py` and the two C++ sources contain the fixed-factor stock/stress rotation used in the theta=0.8 scan. The C++ source requires a C++17 shared-library build; the Python kernel wrapper accepts its path. The rotation scan used the separately calibrated protected-curve baseline, whose parameter record is retained locally in `../model/` alongside the VIX-only two-speed reference and scan selection; these records are excluded from the public branch. These are experimental working references, not an adopted joint calibration.

These components do not independently reconstruct historical conditioning inputs, control coefficients, normalizers or path caches. Those remain in the local experiment archive. Reusing them correctly requires the original upstream assumptions and rebuilding dependent quantities after model changes. The full experiment drivers and historical Python module names also remain local; they are not included in this curated public package.
