SPX-VIX calibration lessons - LaTeX source bundle

Build from this directory:
  tectonic -X compile spx_vix_calibration_lessons.tex

Alternatively use a standard LaTeX installation with the listed packages.
The figures/ directory is required and included. No project source code or
experiment runs are needed to compile the report. The evidence manifest
records the hashes of local records referenced in the report as reviewed
on 28 October 2026. These source records are not included in this bundle.

The report synthesizes archived experiments; no new calibration or Lean
audit was performed. See the evidence register for scope and limitations.
