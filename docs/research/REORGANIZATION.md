# Option-pricing reorganization and publication curation

The complete local workspace groups option-pricing implementation under `code/`, tests under `code/tests/`, and historical reports under `reports/`. The package search path retains the existing Python module names there. Compatibility links support scripts that expect historical neighboring files.

The public subset retains original M2 pricing diagnostics and the experimental current-reference components in `option_pricing/current/`: the conditional two-speed VIX calculation and the fixed-factor stock/stress rotation. The unchanged two-speed candidate record, the protected-curve baseline used for the stock scan, and the theta = 0.8 selection are in `option_pricing/model/`. These are working references, not an adopted joint calibration. The two-speed VIX and stock rotation results have distinct upstream calibration and checking dependencies; the retained components and parameter records do not independently reproduce the complete pricing workflows. See the current-component README for the inputs required.

Detailed experiment drivers, reports and run directories, including frozen source snapshots and simulation arrays, remain in the local workspace. They are excluded from the current public tree, as are formalization and literature. The research history and selected figures remain available here. Earlier commits retain previously published files; this cleanup does not rewrite that history.

The reorganization check compared 117 relocated reports with the earlier commit and found only navigation changes. The preservation checker verified 13 selected figures and the recorded evidence available locally. The full local pricing suite ran 111 tests with the same three pre-existing missing-fixture or missing-kernel errors before and after the move. The extracted two-speed prices, forwards, Jacobians and path outputs, and the rotation formula, were compared with their original implementations on synthetic inputs and matched exactly. A clean checkout passed the current-component derivative and rotation tests, both original M2 diagnostic import checks, and a C++ rotation-kernel build. These checks do not establish complete reproducibility or a joint calibration.

In the curated checkout the original M2 package suite passed 124 tests when given the locally supplied market snapshot. Without that excluded dataset, 123 passed and one errored because its quote CSV was absent.
